Keys to know

⌘⇧MComment on the selected text
⌘SOpen or hide the chat
⌘DShow or hide the comments
⌘EShow or hide the contents
⌘⇧.Write a note to improve the app

⌘ is Ctrl on Linux and Windows. All the keys of each viewer are in HOTKEYS.md.

The viewers8 / 8
These five keys work in all the viewers. Each viewer has more keys, for example to run a cell in pyview or to zoom in pdfview. The file HOTKEYS.md lists all of them.
