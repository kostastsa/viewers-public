Install once, then open any file

# install: git and Python 3.9 or newer
git clone https://github.com/kostastsa/viewers-public ~/tools/viewers
~/tools/viewers/install.sh

# open a file
mdview notes.md        pdfview paper.pdf      texview paper.tex
pyview analysis.py     pageview page.md       plateview deck ~/tools/viewers/onboarding
macOSThe viewers are made and tested on the Mac. The installer also makes apps that open files from Finder.
LinuxThey move easily: the same installer works. Get pandoc, poppler and latexmk from the package manager.
WindowsUse WSL, as on Linux. A native port must replace the fcntl locks, the process groups and the installer.

Disclaimer: nobody tested the viewers on Linux or on Windows. ONBOARDING.md gives the steps as a guide.

The viewers7 / 8
Run the install script one time. Then open a file with the command of its viewer. The last command opens this deck. The viewers are made for macOS. They use only the Python standard library and POSIX functions, so they move easily to Linux. On Windows, install them in WSL. A native Windows version needs other file locks, another way to stop the processes, and a PowerShell installer. ONBOARDING.md gives the details.
