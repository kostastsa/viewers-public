Chat about the open file

  • Click Chat, or push ⌘S.
  • Ask a question about the file, or about the selected part.
  • Claude reads the file, answers, and can change it.
    Tick Ask only for answers without changes.
  • With two Claude Code accounts or more, or a local Ollama model, select it next to New.
    With one account, the chat uses ~/.claude.
